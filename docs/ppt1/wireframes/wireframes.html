P11   关键交互说明
点赞点击 → 即时状态切换（乐观更新）→ 失败回滚 + Toast
评论点击回复 → 展开输入框 → 提交 → 插入对应楼层下
通知点击通知项 → 标记已读 + 跳转关联帖子/评论
注册输入框失焦 → 前端格式校验 → 后端唯一性校验
发帖选择板块 → 填写标题/内容 → 发布（或保存草稿）
Toast操作成功/失败统一顶部弹出，3s 自动消失
Loading列表/详情页骨架屏，提交按钮 Loading 态
Empty统一空状态插画 + 引导文案
Error网络异常/500/404 统一错误页 + 重试按钮
Confirm删除/封禁等操作弹出确认对话框
色彩 #4A90D9 主色 #52C41A 成功 #FF4D4F 错误 #FAAD14 警告
字体 正文 14px / 标题 18px 行高 1.5 字体 PingFang SC / Microsoft YaHei
组件库 Element Plus (Vue 3) — 统一使用，避免自定义样式不一致
断点 Mobile < 768px Tablet 768-1024px Desktop > 1024px
